# 15 — Risks and Open Questions

Status: **PHASE D — AWAITING OWNER APPROVAL** (rev. 2026-10-11; Phase C remediation in
[18](18-remediation-register.md), Phase D consolidation in [19](19-owner-decisions.md)).
Nothing here is disguised as an assumption: each item states
what is known, what is not, and how it will be resolved. Question rows carry a **status**: four are
`OWNER_APPROVAL_REQUIRED` and are collected in [19-owner-decisions.md](19-owner-decisions.md);
everything else has a source-resolved answer or a recommended default already adopted across the
specification. Statuses: `RESOLVED_BY_SOURCE`, `RECOMMENDED_DEFAULT`, `DEFERRED_FROM_V1`,
`OWNER_APPROVAL_REQUIRED`, `OWNER_APPROVED` — **nothing becomes `OWNER_APPROVED` until the owner
records it in [19 §6](19-owner-decisions.md)**; "recommended" is never written as "approved".

## 2. Open questions — status and V1 position (Phase D)

Each row states its **status**, the V1 position and the reasoning. `RECOMMENDED_DEFAULT` is adopted
unless the owner objects; `DEFERRED_FROM_V1` items may return later with their own safety contract;
`RESOLVED_BY_SOURCE` items are answered by source evidence or an established requirement;
`OWNER_APPROVAL_REQUIRED` items are the four decisions in
[19-owner-decisions.md](19-owner-decisions.md). Nothing is `OWNER_APPROVED` yet.

| # | Question | Status | V1 position | Why / alternatives |
|---|---|---|---|---|
| Q-01 | Mutator dry-run default | `RECOMMENDED_DEFAULT` | **Mutating calls do not apply unless the caller explicitly requests it (`dry_run=false`)** — `plugin_write` AND `plugin_modulation` create/update/remove | Fail-safe default; the POC's batch-first (`dry_run=false`) traded one round-trip for immediacy at the cost of accidental writes. Cost: one explicit apply round-trip per mutation |
| Q-02 | Provider placement + codec isolation | `OWNER_APPROVAL_REQUIRED` → [19 Decision 2](19-owner-decisions.md) | **Keep the `PluginProvider`/`StateCodec` boundary; in-repo isolated provider package `plugins/providers/vital/`; NEVER import the legacy `_b4_lib` chain.** Codec: (a) extract the verified host-free function set ([17 AV-13](17-planning-evidence-index.md)); (b) clean re-implementation against the same fixtures as fallback | Phase-A's out-of-tree position is superseded (provider runtime outside the reviewed repo, tests unable to ship with the contracts); (b) risks drift on a byte-exact algorithm; registry data stays external, read through a configured directory |
| Q-03 | Version policy for unmeasured plugin versions | `RECOMMENDED_DEFAULT` | **Refuse writes for unmeasured/incompatible versions.
